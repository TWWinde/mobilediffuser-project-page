# MobileDiffuser project page

Static project page for [MobileDiffuser](https://github.com/TWWinde/MobileDiffuser/tree/MCL):
distilled Stable Diffusion 3 Medium on the iPhone Neural Engine (512 px and 1024 px, with ReSeed).

Plain HTML/CSS/JS, no build step. Preview locally:

```bash
python3 -m http.server 8765
```

All numbers on the page come from on-device measurements documented in the main repository
(`docs/ANE_1024.md`, `docs/RESEED.md`).
